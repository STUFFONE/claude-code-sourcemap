Create or refresh the current task board.

Use TodoWrite for active multi-step work. Organize tasks by outcome, not by role title. Mark exactly one task in progress when work is active. Include review and verification tasks when the change has meaningful risk.

Keep the user-facing board concise. Do not print secrets or auth tokens.
